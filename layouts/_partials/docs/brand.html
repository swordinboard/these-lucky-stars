{{- /* brand — the sidebar site title. Theme partial, OVERRIDDEN here. The theme prints the title as one text node: `{{ .Site.Title }}`. That cannot be laid out as a lockup, because CSS has no way to address part of a text node — so the split has to happen here, in the template. WHAT THIS BUILDS These Lucky ✦ Stars ✦ The last word drops to its own line, centred against the line above it, with a small four-point star either side. THE SPLIT IS DERIVED, NOT HARDCODED. It takes the last word of .Site.Title rather than the literal string "Stars", so renaming the site in hugo.toml cannot leave a lockup that says something the config does not. A one-word title falls back to the theme's plain single span — the lockup needs two parts to be a lockup. THE STARS ARE INLINE SVG, NOT A GLYPH. ✦ (U+2726) is not in Georgia and is not in the Cinzel subsets shipped in static/fonts/, so a glyph would render from whatever fallback font the reader happens to have — or as a tofu box. The site title is the one place still using a webfont and the one thing that visibly broke when the PWA served a cached page; it should not depend on a second font resolving. `currentColor` keeps them on the title's colour in both themes. Styling is in assets/_custom.scss under `.book-brand`. */ -}} {{- $words := split .Site.Title " " -}} {{- $n := len $words -}}
