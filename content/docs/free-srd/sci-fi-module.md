# Sci-Fi Starter Module

This page links to useful information specific to a sci-fi themed setting in a
space environment, whether that be enterprising traders, ambitious space pirates,
or explorers on strange planets.

It is a **quick reference**: every entry the module adds, one line each, linked
to its full rules. Read it to see the module as a whole, or use it as the
grab-and-go list when you are building a setting and want the sci-fi layer
without reading the whole SRD.

Nothing here is maintained by hand. Each table is generated from the blocks
themselves, so a new sci-fi ability appears the moment it is written.
