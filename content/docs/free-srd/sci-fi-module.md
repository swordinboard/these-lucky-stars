# Sci-Fi Starter Module

This page links to useful information specific to a sci-fi themed setting in a
space environment, whether that be enterprising traders, ambitious space pirates,
or explorers on strange planets.

Everything here also appears in context elsewhere in the SRD — abilities in the
Sci-Fi tabs on the Abilities page, equipment on its catalog page — so you never
have to switch pages mid-session. This page is the module read as a whole: what
you get when you set the dial to a spacefaring setting.

Nothing on this page is a copy. Each entry is the same block shown on its home
page, so the two can never drift apart.
