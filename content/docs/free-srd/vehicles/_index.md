## Vehicles

Statted vehicles and mounts. Vehicles are grouped by setting, the same way
creatures and character options are: the core list holds anything that works in
any setting, and each module adds its own.

The rules these stat blocks are read against — size in spaces, speed tiers,
driving, boarding, collision damage, and how mounts differ from machines — live
on [Vehicle Rules](/docs/free-srd/core-rules/vehicle-rules/).
