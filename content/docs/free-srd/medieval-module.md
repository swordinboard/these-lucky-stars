# Medieval Module

A planned starter module covering fantasy and pre-industrial settings — arms, armor, and the character options that go with them.

Nothing here is written yet. When it is, this page will collect the module the
same way the [Sci-Fi Module](/docs/free-srd/sci-fi-module/) does — rules
additions, character options and equipment catalogs, in one quick-reference
sheet generated from the blocks themselves.

See the [roadmap](/docs/roadmap) for where this sits in the plan.
