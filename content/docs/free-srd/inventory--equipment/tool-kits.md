# Tool Kits

Tool kits are pre-assembled collections of tools and supplies built for a
specific type of task — repair, medicine, breaking and entering, and so on.

A kit must be **equipped** to be used efficiently, to one or more body slots as
noted in its description. Kit contents vary by setting, so always read the
description of the kit in front of you rather than assuming.

**Kit supplies.** Most actions using a kit also consume supplies. Each kit comes
with a max supply of 1d12. Some actions need only the tools and no supplies —
those can still be performed once a kit's supply is depleted. Refills cost --Cr
and generally weigh a quarter of the full kit.

## Available kits

Individual kits come from setting modules, since what a repair kit contains
depends entirely on what there is to repair. The sci-fi module has the only
catalog so far:

- [Sci-Fi Tool Kits](/docs/free-srd/inventory--equipment/sci-fi-equipment/sci-fi-kits/)

A setting-agnostic set of kits is planned for this page. Until it is written,
use the sci-fi kits as a model and adjust names and contents to fit your
setting — the supply and equip rules above hold either way.

Kits also appear in character options: the [B&E Kit](/docs/free-srd/character-creation/proficiencies/#be-kit-proficiency),
[Disguise Kit](/docs/free-srd/character-creation/proficiencies/#disguise-kit-proficiency)
and [Repair Kit](/docs/free-srd/character-creation/proficiencies/#repair-kit-proficiency)
proficiencies each train a character in one, and
[Kit Trap](/docs/free-srd/character-creation/abilities/#kit-trap) turns one into
a trap.
