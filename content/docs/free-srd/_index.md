# Free SRD

These Lucky Stars is a tabletop roleplaying game built for dynamic play balancing detail and speed.

The system is built in a series of starter modules intended to help GMs build specific settings. Each starter module is intended to cover a range of related settings and allow the GM to set the dial to exactly where they want. Good examples of this can be seen in the Sci-Fi armor list — which includes a modern EVA space suit alongside futuristic Evosuits.

## Where to Start
If you're new here, especially as a GM, you might start with [the Basics](/docs/free-srd/core-rules/basics). Get to know key terms, the 2d6 resolution system, and general rules of play. Some players prefer to jump right into [character creation](/docs/free-srd/character-creation/character-creation-overview). If that is the case, suggested reading has been added to that page to provide some direction when questions arise.

## System Features
These Lucky Stars is a classess rules moderate tabletop RPG featuring a 2d6 resolution system, [eight attributes](/docs/free-srd/core-rules/attributes), a unique [health system](/docs/free-srd/core-rules/health), and a building blocks structure that allows Game Masters to build a ruleset that reflects their intended setting.

## Design Philosophy
The system aims to:
- be simple enough to learn without previous experience
- be detailed enough to cover most situations without getting bogged down
- allow enough freedom for the GM to comfortably make calls on the fly
- provide a customizable take home experience that allows GMs to dial in on their setting

## Who Is This For
These Lucky Stars is intended for GMs and players seeking customization and freedom. As a core system it is system agnostic, but when paired with setting modules it allows GMs to use the system as a tool to hone in on their setting rather than fit a bland system with no settign content direction. It also allows players freedom over their character during creationa and level up, allowing players to adapt their character's growth rather than be locked in with a class selection.

## What's Free
All core mechanics are free and will remain free forever. This documentation site contains everything you need to play and will remain accessible even thorugh the messy building and editing phases. Licensing information can be found [here](/docs/legal).

## What's Coming
Complete These Lucky Stars setting modules will include expanded character options, equipment catalogs, vehicles, creatures, setting lore, and adventures. A PDF builder is in the earliest phases of development, and will allow users to create custom printable PDFs of rules, feature and equipment lists, and anything else found on the site. In the future, we hope to see print versions of the core rules and modules. The [roadmap](/docs/roadmap) is periodically updated to reflect the direction of the project.
