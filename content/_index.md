### Related Web Apps:

[Digital Character Sheet](/digitalcharactersheet.html)
This character sheet was made on a whim. It should have everything the basic paper sheet has. Check the READ ME  at the top for more details.

[Attribute Converter](/attributeconverter.html)
This converter generates comparable stat arrays based on probability and overall strength. It can be used to transfer between TLS test versions, as well as the most common D20 systems. originally intended for a specific shift during playtesting, it serves as a handy tool for judging attribute arrays.

[Planet Name Generator](/planetnamegenerator.html)
This was made to generate planet names during the sci-fi playtesting. It really generates planet codes, not so much names.
