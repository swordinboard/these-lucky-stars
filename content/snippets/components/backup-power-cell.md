*--Cr // 6lbs // Belt // External // [Battery](/docs/free-srd/inventory--equipment/item-tags/#battery) [Medium]*

A secondary housing providing instant access to a battery of the same size as the machines primary power source.  While installed, switching which battery is actively powering the machine costs 1 AP. If the primary power source is depleted the system automatically switches to the backup instantly. Physically removing or replacing either battery still takes the standard ten minutes and use of the tech kit with supplies.

Occupies the Belt slot for other equipment.
