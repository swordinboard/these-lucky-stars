*–Cr — 2lbs — Belt — External*

An automated diagnostic and minor repair system built into the host's frame. The host recovers 1 VIT per completion of a 6hr Rest Mode cycle. Requires 2 supply rolls od the host's power source. Does not function if the host is at 0 VIT or has the dying condition. Does not repair wounds or conditions. 

Occupies the Belt slot for other equipment.
