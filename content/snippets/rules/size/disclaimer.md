> [!IMPORTANT]
> The rules and content provided are written for an average party size of medium (1) using the measurement ranges provided for height and space. Basic instructions for adapting the size categories to a different set of measurements are provided. While These Lucky Stars can be played with a wide ranging party size, keeping the party within a range of 3 size categories makes for less bookkeeping and smooth play.
