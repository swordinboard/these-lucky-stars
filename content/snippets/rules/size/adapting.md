These Lucky Stars plays best when medium (size 1) is used for the party size. To account for this it can be adapted to use any set of measurements for that range by following a simple rule: *Expected height measurements double at each upward interval and half at each downward interval.* With this rule governing expected height, it also acts as a base for footprint and reach.

To adapt the base size, start by determining the intended low range for the typical height of size medium, then double it for large, and half it for small. The same is then done to find huge and tiny respectively. Expected width is half the low end of the height range, while wingspan is equal to three times that. The measurement of a space is then determined by increasing the low range of the medium size by 25-50%, and can be rounded to the nearest convenient number. This by no means needs to be a perfect calculation, and is entirely up to the GM when creating their game. 5ft spaces are used in rules writing because they are familiar and easy to use, not because they are mathematically perfect. The number of occupied spaces for each size category remains the same on the chart regardless of measurement ranges applied.
