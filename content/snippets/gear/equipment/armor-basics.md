Armor provides a DEF Bonus at the cost of an AGI/DEX penalty, based on how restrictive it is. Some armors include built-in upgrades or special properties.

**DEF Bonus** — The bonus provided to the wearer's DEF.
**Object DEF** — The armor's own structural DEF used as a fallback if the armor is attacked directly rather than degraded through use/wear, usually limited to when an armor is not worn. See [Damaged & Broken Gear](/docs/free-srd/core-rules/damaged--broken-gear/#breaking-defensive-items) for more on object durability.
**AGI/DEX Penalty** — A penalty applied to AGI and DEX. Bulkier armor restricts movement more.
